# PureHaven — Cleaning Business Website

A responsive, single-page marketing website concept for a cleaning service. Built with plain HTML, CSS and JavaScript: no framework, build step, API key or paid package required.

## Run it on your computer

1. Extract the ZIP folder.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Click around and test the navigation, service links, package links and quote form.

For a better local development workflow, open the folder in Visual Studio Code and use a local preview extension, or run a local web server.

## Important before a real business uses it

This is a **demo/template**, not an operating cleaning company. Do not present the sample brand as a real established business.

- Replace `hello@example.com` in `script.js` with the actual business inbox.
- Update all service descriptions, pricing/packages, policies, service area and contact details to match the buyer's real business.
- The quote form currently opens the visitor's email app using `mailto:`. It does **not** send data to a server or store leads. To receive submissions without relying on the visitor's email app, connect a form service or backend and test it.
- Pricing packages are examples, not verified market prices.
- No real customer reviews or performance claims are fabricated or included.
- The photos are loaded from Unsplash URLs and require an internet connection. Check image licenses/terms and keep appropriate attribution if required by the source/selected image. For a production handoff, consider downloading appropriately licensed images and hosting them with the site.
- Google Fonts are loaded externally; system fallback fonts are included.
- Check the name “PureHaven” for trademark/domain conflicts before commercial use.

## Publish free (static demo)

You can publish the site using GitHub Pages or another static host. This project has no server-side code, so static hosting is enough for the demo. A custom domain generally costs money; the free host subdomain is sufficient for a portfolio demo.

## Project files

- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile menu, form prefill and email-draft behavior
